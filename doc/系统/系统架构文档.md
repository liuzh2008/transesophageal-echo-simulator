## 系统概述

经食管超声心动图模拟器（TEE Simulator）是一个基于Python和VTK的医学影像可视化应用程序，主要用于：

- **DICOM影像加载与解析**：支持加载DICOM文件和文件夹
- **3D体积渲染**：使用VTK进行高质量3D可视化
- **2D切片显示**：支持横切面显示，模拟TEE扇形视图
- **切割平面功能**：在3D模型中显示切割平面（红色线条+浅红色填充）
- **多渲染模式**：体积渲染、表面渲染、线框渲染

### 主要特性

| 特性 | 描述 |
|------|------|
| DICOM支持 | 支持标准DICOM格式，自动识别文件 |
| 3D可视化 | 基于VTK的GPU加速体积渲染 |
| TEE扇形视图 | 模拟经食管超声的扇形显示方式 |
| 切割平面 | 支持在任意位置创建切割平面 |
| 患者信息 | 自动提取并显示DICOM中的患者信息 |
| 透明度控制 | 实时调整3D模型透明度 |

## 核心模块

### 1. 核心层 (Core Layer)

#### 1.1 DICOMLoader (dicom_loader.py)

**职责**: 负责DICOM文件的加载、解析和数据提取

**主要功能**:
- 加载单个DICOM文件
- 批量加载DICOM文件夹
- 提取患者信息（ID、姓名、检查日期等）
- 提取图像数据和体积数据
- 支持窗宽窗位调整
- 自动按切片位置排序

**核心类**:
```python
class DICOMLoader:
    - load_file(file_path: str) -> bool
    - load_directory(dir_path: str) -> bool
    - get_patient_info() -> Dict[str, Any]
    - get_volume_data() -> Optional[np.ndarray]
    - get_spacing() -> Tuple[float, float, float]
    - get_origin() -> Tuple[float, float, float]
```

#### 1.2 VolumeRenderer (volume_render.py)

**职责**: 负责3D体积渲染和可视化

**主要功能**:
- 体积渲染（GPU光线投射）
- 表面渲染（Marching Cubes算法）
- 多平面重建（MPR）
- 切割平面创建（红色线条+浅红色填充）
- 透明度控制
- numpy数组与VTK图像数据转换

**核心类**:
```python
class VolumeRenderer:
    - set_volume_data(volume_data, spacing, origin)
    - create_volume_actor() -> Optional[vtk.vtkVolume]
    - create_surface_actor(threshold: float) -> Optional[vtk.vtkActor]
    - create_cut_plane(position_percent, normal, return_data) -> Tuple[Actor, Actor, PolyData]
    - update_opacity(opacity_value: float)
    - get_vtk_image_data() -> Optional[vtk.vtkImageData]
```

#### 1.3 TEESimulator (tee_simulator.py)

**职责**: TEE模拟器（简化版本，已移除探头功能）

**主要功能**:
- 心脏模型参数管理
- RAO/LAO角度计算
- 平面法线向量计算

**核心类**:
```python
class TEESimulator:
    - set_heart_model(center, radius)
    - calculate_plane_normal_from_angles(rao_angle, lao_angle) -> Tuple[float, float, float]
    - get_info() -> Dict[str, Any]
```

## 技术栈

### 核心技术

| 技术 | 版本 | 用途 |
|------|------|------|
| Python | 3.8+ | 编程语言 |
| PyQt5 | 5.15+ | GUI框架 |
| VTK | 9.0+ | 3D可视化 |
| NumPy | 1.20+ | 数值计算 |
| pydicom | 2.3+ | DICOM处理 |

### 渲染技术

| 技术 | 描述 |
|------|------|
| GPU Volume Ray Casting | GPU加速体积光线投射渲染 |
| Marching Cubes | 等值面提取算法 |
| vtkImageReslice | 图像切片提取 |
| vtkImagePlaneWidget | 交互式平面切割 |

### 坐标系统

- **DICOM坐标系**: (X, Y, Z) - 患者坐标系
- **VTK坐标系**: (X, Y, Z) - 世界坐标系
- **numpy数组**: (Z, Y, X) 或 (Y, X, Z) - 数组索引
