# 模块接口文档

## 概述
本文档记录了经食管超声心动图模拟器重构后的模块接口。按照关注点分享原则，应用程序被重构为五个主要模块。

## 接口列表

### 1. UI组件模块 (`src/gui/ui_components.py`)

**模块功能**：负责创建应用程序的所有UI组件，实现UI创建逻辑与业务逻辑的分离。

**主要接口**：

#### `UIComponents.create_menu_bar(parent)`
**功能说明**：创建应用程序的菜单栏
**请求参数**：
- `parent`: QWidget - 父窗口部件
**响应格式**：
- 返回元组 `(menubar, actions_dict)`
  - `menubar`: QMenuBar - 创建的菜单栏
  - `actions_dict`: dict - 包含所有菜单动作的字典
**逻辑**：
1. 创建文件菜单（打开DICOM文件、打开DICOM文件夹、退出）
2. 创建视图菜单（3D视图切换）
3. 创建帮助菜单（关于信息）
**响应示例**：
```python
menubar, actions = UIComponents.create_menu_bar(self)
self.setMenuBar(menubar)
```

#### `UIComponents.create_tool_bar(parent)`
**功能说明**：创建应用程序的工具栏
**请求参数**：
- `parent`: QWidget - 父窗口部件
**响应格式**：
- 返回元组 `(toolbar, actions_dict)`
**相关文件**：`src/gui/ui_components.py`

#### `UIComponents.create_patient_panel()`
**功能说明**：创建患者信息面板
**响应格式**：
- 返回元组 `(panel, labels_dict)`
  - `panel`: QGroupBox - 患者信息面板
  - `labels_dict`: dict - 包含所有标签控件的字典

#### `UIComponents.create_view_options_panel()`
**功能说明**：创建视图选项面板
**响应格式**：
- 返回元组 `(panel, controls_dict)`
  - `panel`: QGroupBox - 视图选项面板
  - `controls_dict`: dict - 包含所有控制控件的字典
    - `view_3d_checkbox`: QCheckBox - 3D视图显示复选框
    - `render_combo`: QComboBox - 渲染模式下拉框
    - `opacity_slider`: QSlider - 透明度滑块
    - `cut_plane_button`: QPushButton - 切割平面按钮
**逻辑**：
1. 创建视图切换复选框
2. 创建渲染模式下拉框
3. 创建透明度滑块
4. 创建切割平面按钮（红色样式）
5. 返回面板和控制字典
**相关文件**：`src/gui/ui_components.py`

### 2. VTK管理器模块 (`src/gui/vtk_manager.py`)

**模块功能**：负责VTK渲染相关逻辑，管理3D视图的创建、更新和交互。

**主要接口**：

#### `VTKManager.__init__(parent_widget=None)`
**功能说明**：初始化VTK管理器
**请求参数**：
- `parent_widget`: QWidget (可选) - 父窗口部件
**逻辑**：
1. 检查VTK可用性
2. 初始化VTK组件
3. 创建默认测试几何体

#### `VTKManager.get_vtk_widget()`
**功能说明**：获取VTK小部件
**响应格式**：
- 返回 `QVTKRenderWindowInteractor` 或 `None`
**相关文件**：`src/gui/vtk_manager.py`

#### `VTKManager.set_volume_data(image_data, spacing=None, origin=None)`
**功能说明**：设置体积数据并更新3D视图
**请求参数**：
- `image_data`: numpy.ndarray - 3D体积数据
- `spacing`: tuple (可选) - 体素间距 (x, y, z)
- `origin`: tuple (可选) - 数据原点坐标
**响应格式**：
- 返回 `bool` - 操作是否成功
**逻辑**：
1. 调用core模块的volume_renderer
2. 创建体积演员
3. 更新渲染器
4. 重置相机

#### `VTKManager.change_render_mode(mode)`
**功能说明**：更改渲染模式
**请求参数**：
- `mode`: str - 渲染模式 ("体积渲染", "表面渲染", "线框渲染")
**逻辑**：
1. 根据模式创建相应的演员
2. 更新渲染器
3. 重新渲染视图

#### `VTKManager.change_opacity(opacity_value)`
**功能说明**：更改模型透明度
**请求参数**：
- `opacity_value`: int - 透明度值 (0-100)
**逻辑**：
1. 将整数值转换为浮点数 (0.0-1.0)
2. 更新所有演员的透明度属性
3. 重新渲染视图

#### `VTKManager.show_cut_plane(position_percent=0.5, normal=(0, 0, 1), show_2d_window=True)`
**功能说明**：显示切割平面（红色线条+浅红色填充）并可选显示2D切片窗口
**请求参数**：
- `position_percent`: float (可选) - 切割位置百分比 (0.0-1.0)，默认0.5表示50%位置
- `normal`: tuple (可选) - 平面法线向量，默认(0, 0, 1)垂直于Z轴
- `show_2d_window`: bool (可选) - 是否显示2D切片窗口，默认True
**响应格式**：
- 返回 `bool` - 操作是否成功
**逻辑**：
1. 检查VTK可用性和体积数据
2. 调用core模块的volume_renderer.create_cut_plane方法
3. 将切割平面Actor添加到渲染器
4. 如果show_2d_window为True，调用show_cross_section_window方法
5. 重新渲染视图
**相关文件**：`src/gui/vtk_manager.py`, `src/core/volume_render.py`

#### `VTKManager.show_cross_section_window(cut_position, normal_vector=None)`
**功能说明**：显示2D切片窗口（垂直于切割平面的2D切片图像）
**请求参数**：
- `cut_position`: float - 切割位置（百分比）
- `normal_vector`: tuple (可选) - 平面法线向量，默认(0, 0, 1)
**响应格式**：
- 返回 `CrossSectionWindow` 或 `None` - 创建的2D切片窗口
**逻辑**：
1. 从volume_renderer获取vtkImageData
2. 调用cross_section_window.create_cross_section_window创建窗口
3. 保存窗口引用避免被垃圾回收
4. 返回窗口实例
**相关文件**：`src/gui/vtk_manager.py`, `src/gui/cross_section_window.py`, `src/core/volume_render.py`

### 3. DICOM管理器模块 (`src/gui/dicom_manager.py`)

**模块功能**：负责DICOM文件加载和处理，与core模块的dicom_loader交互。

**主要接口**：

#### `DICOMManager.load_file(file_path)`
**功能说明**：加载单个DICOM文件
**请求参数**：
- `file_path`: str - DICOM文件路径
**响应格式**：
- 返回 `bool` - 加载是否成功
**逻辑**：
1. 获取core模块的dicom_loader
2. 调用load_file方法
3. 记录当前文件路径
**相关文件**：`src/gui/dicom_manager.py`, `src/core/dicom_loader.py`

#### `DICOMManager.load_directory(dir_path)`
**功能说明**：加载DICOM文件夹
**请求参数**：
- `dir_path`: str - DICOM文件夹路径
**响应格式**：
- 返回 `bool` - 加载是否成功
**逻辑**：
1. 获取core模块的dicom_loader
2. 调用load_directory方法
3. 记录当前文件夹路径

#### `DICOMManager.get_patient_info()`
**功能说明**：获取患者信息
**响应格式**：
- 返回 `dict` - 包含患者信息的字典
  - `patient_id`: str - 患者ID
  - `patient_name`: str - 患者姓名
  - `study_date`: str - 检查日期
  - `modality`: str - 模态

#### `DICOMManager.get_volume_data()`
**功能说明**：获取体积数据
**响应格式**：
- 返回 `numpy.ndarray` 或 `None`

#### `DICOMManager.get_spacing()`
**功能说明**：获取间距信息
**响应格式**：
- 返回 `tuple` 或 `None`

#### `DICOMManager.get_origin()`
**功能说明**：获取原点信息
**响应格式**：
- 返回 `tuple` 或 `None`

### 4. 事件处理器模块 (`src/gui/event_handlers.py`)

**模块功能**：负责处理用户事件，将UI事件与业务逻辑解耦。

**主要接口**：

#### `EventHandlers.__init__(main_window, vtk_manager, dicom_manager)`
**功能说明**：初始化事件处理器
**请求参数**：
- `main_window`: MainWindow - 主窗口实例
- `vtk_manager`: VTKManager - VTK管理器实例
- `dicom_manager`: DICOMManager - DICOM管理器实例
**逻辑**：
1. 保存管理器引用
2. 初始化UI组件字典

#### `EventHandlers.set_ui_components(ui_components)`
**功能说明**：设置UI组件引用
**请求参数**：
- `ui_components`: dict - UI组件字典
**相关文件**：`src/gui/event_handlers.py`

#### `EventHandlers.handle_open_file()`
**功能说明**：处理打开文件事件
**逻辑**：
1. 显示文件选择对话框
2. 调用DICOM管理器加载文件
3. 更新患者信息显示
4. 更新3D视图

#### `EventHandlers.handle_open_directory()`
**功能说明**：处理打开文件夹事件
**逻辑**：
1. 显示文件夹选择对话框
2. 调用DICOM管理器加载文件夹
3. 更新患者信息显示
4. 更新3D视图

#### `EventHandlers.handle_toggle_3d_view(checked)`
**功能说明**：处理切换3D视图事件
**请求参数**：
- `checked`: bool - 复选框状态
**逻辑**：
1. 显示/隐藏3D视图框架
2. 更新状态栏消息

#### `EventHandlers.handle_change_render_mode(mode)`
**功能说明**：处理更改渲染模式事件
**请求参数**：
- `mode`: str - 渲染模式
**逻辑**：
1. 调用VTK管理器更改渲染模式
2. 更新状态栏消息

#### `EventHandlers.handle_change_opacity(value)`
**功能说明**：处理更改透明度事件
**请求参数**：
- `value`: int - 透明度值
**逻辑**：
1. 调用VTK管理器更改透明度
2. 更新状态栏消息

#### `EventHandlers.handle_show_cut_plane()`
**功能说明**：处理显示切割平面事件
**逻辑**：
1. 检查VTK可用性
2. 检查体积数据是否存在
3. 调用VTK管理器的show_cut_plane方法
4. 显示成功/失败状态消息
**响应格式**：
- 无返回值，通过状态栏显示操作结果
**相关文件**：`src/gui/event_handlers.py`, `src/gui/vtk_manager.py`

### 5. 主窗口模块 (`src/gui/main_window.py`)

**模块功能**：作为应用程序的主控制器，协调各个模块的工作。

**主要接口**：

#### `MainWindow.__init__()`
**功能说明**：初始化主窗口
**逻辑**：
1. 设置窗口基本属性
2. 初始化各个管理器
3. 初始化用户界面
4. 设置事件处理器

#### `MainWindow.init_ui()`
**功能说明**：初始化用户界面
**逻辑**：
1. 创建中央部件和主布局
2. 创建菜单栏和工具栏
3. 创建主内容区域
4. 创建状态栏
5. 设置事件处理器连接

#### `MainWindow.create_menu_bar()`
**功能说明**：创建菜单栏
**逻辑**：
1. 调用UIComponents.create_menu_bar
2. 保存菜单动作引用

#### `MainWindow.create_tool_bar()`
**功能说明**：创建工具栏
**逻辑**：
1. 调用UIComponents.create_tool_bar
2. 保存工具栏动作引用

#### `MainWindow.create_main_content(main_layout)`
**功能说明**：创建主内容区域
**请求参数**：
- `main_layout`: QVBoxLayout - 主布局
**逻辑**：
1. 创建水平分割器
2. 创建3D视图区域
3. 创建信息面板区域
4. 添加各个面板到布局

#### `MainWindow.setup_event_handlers()`
**功能说明**：设置事件处理器连接
**逻辑**：
1. 设置UI组件引用
2. 连接菜单动作信号
3. 连接工具栏动作信号
4. 连接视图控制信号

## 接口使用示例

### 基本使用流程
```python
# 1. 创建主窗口
window = MainWindow()

# 2. 自动加载DICOM数据（通过main.py）
# 3. 用户交互通过事件处理器处理
# 4. 各个模块协同工作
```

### 模块间协作
```
用户操作 → 事件处理器 → DICOM管理器/VTK管理器 → 更新UI
     ↓          ↓              ↓
   信号      业务逻辑       数据/渲染
```

## 注意事项

1. **模块依赖**：各个模块之间有明确的依赖关系，应按正确顺序初始化
2. **错误处理**：所有接口都应包含适当的错误处理
3. **线程安全**：涉及UI更新的操作应在主线程执行
4. **资源管理**：注意VTK资源和文件句柄的释放
