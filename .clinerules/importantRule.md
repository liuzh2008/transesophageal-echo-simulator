- 不要创建测试文件。除非我要求你创建。

## 提交流程规范

每次提交代码时，必须严格按照以下步骤执行：

### 1. JSDoc 注释
- 对本次修改/新增的代码使用 JSDoc 风格注释进行详细注释

### 2. 更新日志
- 总结本次任务，生成更新日志
- 添加到当日日志文件的尾部，路径为 `doc/更新日志/YYYY-MM-DD.md`
- 每天只能有一个更新日志文件

### 3. 版本号更新
- 格式为 `0.1.xxx`
- 在保持前缀 `0.1` 不变的前提下，将后面的数字整体加 1
- 版本号定义在 `src/gui/main_window.py` 的 `MainWindow.VERSION` 类常量中

### 4. 更新小结
- 严格按照下面格式修改根目录下的 `更新小结.md`：
```
### {日期} {时间}
#### 版本号：{版本号}，更新：
- {简要说明更新内容}
```
- 不添加其他内容
- 将本次更新小结添加到文档的最前面，以实现按时间倒序排列

### 5. Git 提交
- 需要提交根目录下的 `更新小结.md` 文件
- 需要分开执行 git 命令
- 先执行 `git add` 添加文件
- 再在终端窗口中执行 `git commit` 提交变更
- 保持相同的提交信息
- 提交后执行 `git push` 推送
